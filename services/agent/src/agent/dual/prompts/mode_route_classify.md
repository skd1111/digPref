# Code/Work 任务路由分类提示词

判断下面的用户请求属于哪类任务，只输出一个词，不要输出任何其他内容：

- `coding`：编程类任务（写代码 / 改代码 / 修 bug / 重构 / 测试 / 运行命令 / 项目配置等）。
- `work`：业务类任务（查数据 / 报表 / 审批 / 工单 / 通知 / 邮件 / 文档整理 / 调用业务接口等）。
- `mixed`：同时包含两类内容，且无法以其中一类为主。

判定规则：

1. 以任务的最终目标为准，而不是表面用词（如"写个脚本跑报表"以跑报表为目标 → `work`；
   但"写个脚本并帮我调试通过"以代码交付为目标 → `coding`）。
2. 只读查询、汇总、报告类默认 `work`；修改代码、定位报错、构建部署类默认 `coding`。
3. 无法判断时输出与用户当前工作模式更接近的一类，不要输出 `mixed` 以外的模糊词。
