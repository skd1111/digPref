## 2. 税率体系（核心）

| 主体 | 税率 | 来源条款 |
|---|---|---|
| 居民企业 / 在中国境内设有机构场所的非居民企业 | **25%**（标准税率） | 第 4 条第 1 款 |
| 符合条件的小型微利企业 | **20%**（实际折算后常见 5%-10%） | 第 28 条第 1 款 |
| 国家需要重点扶持的高新技术企业 | **15%** | 第 28 条第 2 款 |
| 设在深圳河套深港科技创新合作区深圳园区特定封闭区域的企业（特定企业） | **15%** | 实施条例第 93 条（2025 修订新增）|
| 西部鼓励类企业 | **15%** | 实施条例 |
| 非居民企业（在中国境内未设机构场所） | **20%** | 第 4 条第 2 款 |
| 集成电路 / 软件产业 / 重点软件企业 | 减按 **10%** | 第 28 条 + 财税政策 |

## 3. 应纳税所得额（第 2 章核心）

### 第 5 条 · 计算公式
```
应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 以前年度亏损
```

### 第 6 条 · 收入总额（**9 项**）
1. 销售货物收入
2. 提供劳务收入
3. **转让财产收入**（含股权 / 资产 / 债权）
4. **股息、红利等权益性投资收益**
5. 利息收入（**含存款利息、债券利息**）
6. 租金收入
7. 特许权使用费收入
8. **接受捐赠收入**
9. 其他收入

### 第 7 条 · 不征税收入（**3 类**）
- **财政拨款**（政府性基金 / 行政事业性收费）
- **依法收取并纳入财政管理的行政事业性收费**
- **国务院规定的其他不征税收入**

⚠ 注意：财政补贴中**部分**符合条件（国务院规定）的才属于不征税收入；其他多数财政补贴应作为应税收入。

### 第 8 条 · 免税收入（**4 类**）
- 国债利息收入
- 符合条件的居民企业之间的股息、红利等权益性投资收益
- 在中国境内设立机构、场所的非居民企业从居民企业取得与该机构、场所有**实际联系**的股息、红利
- 符合条件的非营利组织的收入

### 第 9 条 · 各项扣除（**13 项**详细规则，实施条例 + 财税公告**）
- 成本、费用、税金、损失、其他支出
- 各扣除项**限额**与不允许扣除项（如罚金、税收滞纳金、赞助支出、与取得收入无关的支出等）
- 重点：**研发费用加计扣除**（一般行业 100% 加计扣除，集成电路和工业母机行业 120%）｜**工资薪金支出**（合理支出可扣除）｜**职工福利费**（≤工资总额 14%）｜**工会经费**（≤2%）｜**教育经费**（≤8%，结转以后年度扣除）｜**业务招待费**（≤营业收入的 5‰，且不超过发生额的 60%）｜**广告费 / 业务宣传费**（一般行业 ≤营业收入 15%，化妆品 / 医药 / 酒类等 ≤30%）｜**公益性捐赠**（≤年度利润总额 12%）

### 第 11 条 · 亏损弥补（**5 年结转**）
- 年度亏损可以用**以后年度所得**弥补，**最长结转年限 5 年**

## 4. 第四章 税收优惠（高频审核点）

### 第 28 条 · 小型微利企业
**判定条件（同时满足）**：
- 从事国家非限制和禁止行业
- 年度应纳税所得额 ≤ **300 万元**（2023 年起标准）
- 从业人数 ≤ **300 人**
- 资产总额 ≤ **5000 万元**

**优惠**：分段超额累进 ——
- 应税所得 ≤ 100 万 → **5%**（减半后再减半）
- 100-300 万 → **5%**（按 25% 标准税率减按 5% 计税）

### 第 28 条第 2 款 · 高新技术企业
**认定条件**：
- 注册成立 1 年以上
- 通过高新技术企业认定（科技部 / 财政部 / 税务总局三部委）
- 拥有核心自主知识产权
- 企业从事研发活动技术领域属于《国家重点支持的高新技术领域》
- **研发费用占比**：销售收入 < 5000 万 → ≥5%；5000 万-2 亿 → ≥4%；≥2 亿 → ≥3%；境内研发占比 ≥60%
- **科技人员占比**：≥10%
- **高新技术产品（服务）收入占比**：≥60%（按 2024 标准）
- 知识产权数量、科技成果转化数量、研究开发组织管理水平等

### 第 30 条 · 研发费用加计扣除
- 制造业研发费用加计扣除比例 **100%**（自 2023 起）
- 集成电路和工业母机行业 **120%**（2023 起）
- 委托境外研发 → 不超过境内符合条件的研发费用 2/3
- **费用化**部分按实际发生额扣除后加计扣除
- **资本化部分**形成无形资产，按无形资产成本 175%/220% 摊销

### 第 31 条 · 创业投资企业优惠
- 创业投资企业投资未上市中小高新技术企业 **2 年（24 个月）以上** → 可按投资额的 **70%** 抵扣应纳税所得额
- 当年不足抵扣的，可结转以后年度

### 第 32 条 · 加速折旧
- 6 大行业（生物药品制造业 / 专用设备制造业 / 铁路 / 船舶 / 航空航天 / 其他）固定资产 → 可缩短折旧年限或采取加速折旧
- **所有行业**2014-01-01 后新购进的专门用于研发的仪器设备 → 单位价值 ≤100 万的，可一次性税前扣除；>100 万的，加速折旧
- **所有行业**5000 元以下设备 → 一次性税前扣除

## 5. 第六章 特别纳税调整（**重点监管**）

### 第 41 条 · 关联交易的判定
关联方包括：
- 股权 / 资金 / 劳务 / 特许权 / 控制关系等

### 第 42 条 · 独立交易原则（**Arm's Length Principle**）
- 税务机关有权**核定应纳税所得额**

### 第 43 条 · 预约定价安排（APA）
- 4 类：单边 / 双边 / 多边 / 其他 → 协商确定计税基础与计价方法

### 第 44 条 · 关联业务往来报告
- 关联方交易 **应按独立企业原则定价**
- 主体收到报告要求 → 60 日内提交资料；情况复杂可延长 30 日
- 不提交 → 税务机关核定

### 第 45 条 · 转让定价反避税
- 由设立、转让财产等行为**不具有合理商业目的**的，税务机关有权**按照合理方法调整**

### 第 46 条 · 资本弱化
- 关联方利息支出**不得税前扣除**：
  - 接受关联方债权性投资与其权益性投资比例 **2:1**（金融企业 5:1）以内的部分

### 第 47 条 · 受控外国企业
- 由居民企业 / 单一居民企业控制，设在实际税负 **<12.5%** 国家的企业 → 利润不分配或少分配，税务机关可**视同分配**，计入当年度所得

### 第 48 条 · 补征税款 + 利息
- 因特别纳税调整**补征税款** + 按**中国人民银行公布的同期同类贷款基准利率加 5 个百分点**计算利息

## 6. 第七章 征收管理（与征管法衔接）

### 第 49 条
- 企业应当**自月份或者季度终了之日起 15 日内**，向税务机关**预缴**企业所得税
- **年度终了之日起 5 个月内**（即 5 月 31 日前）→ **汇算清缴**
- 年度中间终止经营 → 自**实际经营终止之日起 60 日内**汇算清缴

### 第 50 条
- 缴纳地点：除税收法律、行政法规另有规定外，**登记注册地**

### 第 53 条
- 缴纳：纳税人**以人民币计算缴纳**

## 7. 实施条例 2025-01-20 新增要点（**国务院令第 797 号**）

### 第 93 条 · 高新技术企业认定管理
- 新增 **"工业和信息化"** 与**"科技"**并列参与管理（扩大管理主体）

### 河套深港科技创新合作区深圳园区
- 符合条件的鼓励类企业 → 减按 **15%** 征收企业所得税

### 数字 / 智能转型投资
- 2024-01-01 至 2027-12-31
- 企业投入数字化 / 智能化的**专用设备**投资
- 可按投资额的 **10%** 抵免当年应纳税额
- 当年不足抵免的，**可结转 5 年**
- 抵免金额**不超过设备原值的 50%**

### 公益性捐赠电子凭证
- 自 **2024-02-01** 起，公益性捐赠电子 / 纸质凭证**均作为税前扣除有效凭证**

## 8. 提炼：可机审的判定要素（28 项）

### 8.1 收入确认类（R 类，9 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| R01 | 收到货物销售款但未确认收入 | 第 6 条 | **violation** |
| R02 | 提供劳务已交付但未确认收入 | 第 6 条 | **violation** |
| R03 | 转让财产（股权 / 资产）未确认所得 | 第 6 条 | **violation**（含隐藏股权转让未确认） |
| R04 | 取得接受捐赠收入未入账 | 第 6 条 | **violation** |
| R05 | 利息 / 租金 / 特许权使用费到期未确认 | 第 6 条 | warning |
| R06 | 关联方交易定价显著偏离独立交易原则 | 第 42 条 | **high risk**（特别纳税调整） |
| R07 | 关联方资金拆借利息未申报 | 第 46 条 | warning |
| R08 | 收到财政补贴未正确区分应税 / 不征税 | 第 7 条 | warning |
| R09 | 国债利息 / 居民企业间股息未做免税收入 | 第 8 条 | 中性（影响申报准确性） |

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| D01 | 工资薪金超过合理范围（如高管 12 万） | 实施条例第 34 条 | warning |
| D02 | 职工福利费超过工资总额 14% | 实施条例第 40 条 | **violation** |
| D03 | 工会经费超过 2% / 教育经费超过 8% | 实施条例 | warning |
| D04 | 业务招待费超过限额（按发生额 60% 与营业收入 5‰ 孰低） | 实施条例 | **violation** |
| D05 | 广告费 / 业务宣传费超过限额 | 实施条例 | warning |
| D06 | 公益性捐赠超过年度利润总额 12%（超额可结转 3 年） | 实施条例第 53 条 | warning |

| D08 | 罚金 / 税收滞纳金 / 赞助支出扣除 | 实施条例 | **violation** |

## 9. 测试场景映射

| 场景 | 命中条款 |
|---|---|
| S4（合规） | 无（应当全过） |
| V1（违规） | D07 + D08 + R04（隐瞒捐赠收入 + 罚金支出 + 与收入无关支出） |
| V2 | R01（货物销售不入账）+ R05（应计利息未确认）→ 偷税触发 §63 |
| V3 | T02（未按时汇算清缴） |
| V4 | R06（关联方交易偏离 + 转让定价反避税） |
| V5 | A04（资本弱化利息不得扣除） |
| G1 | D09（研发费用加计扣除基数错误，灰区） |
| G4 | A01（关联方 2:1 临界 + 业务实质判断） |

---

**提示**：EAIDE 审核专家模式企业所得税审核的**最高优先级**应当是 **R 类收入确认**（防隐匿收入） + **D 类扣除比例**（防超额扣除） + **T 类时效**（防逾期申报）。A 类（特别纳税调整）可作为 Phase 5 V1.5 接力，需要 LLM 协助判定"实质重于形式"。
