## 2. 总则要点

### 第 4 条 · 发票的合法性
- **发票**是指在购销商品、提供或者接受服务以及从事其他经营活动中，开具、收取的收付款凭证。
- 发票是**会计核算的原始凭证**，是审计机关、税务机关执法的**重要依据**。

### 第 5 条 · 发票种类（由国家税务总局确定）
- 增值税专用发票
- 增值税普通发票
- 增值税电子普通发票
- 增值税电子专用发票
- 通用定额发票
- 通用机打发票
- 机动车销售统一发票
- 二手车销售统一发票
- 航空运输电子客票行程单
- 火车票
- 等

### 第 7 条 · 发票联次
- **基本联次**：存根联（开票方留存） + 发票联（受票方付款凭证） + 记账联（销售方记账凭证）
- 增值税专用发票另有 **抵扣联**（受票方抵扣进项税凭证）
- 省、自治区、直辖市税务机关可按实际需要增减联次并报国家税务总局备案

## 3. 第二章 发票的印制（关键风险点）

### 第 8 条 · 监制章
- 发票应当套印**全国统一发票监制章**；国家税务总局规定式样 + 印制规格
- 未套印监制章 → **不能作为财务报销凭证**

### 第 9-11 条 · 印制许可
- **增值税专用发票**由国家税务总局指定企业印制（高度管控）
- 其他发票由省级税务机关指定企业印制
- 印制企业**不得超量、超范围印制**

### 第 12 条 · 禁止性规定
- 禁止**境外印制**发票在中国境内销售、使用
- 禁止任何单位 / 个人伪造发票监制章

## 4. 第四章 发票的开具（核心业务场景）

### 第 19 条 · 开票主体
- **销售商品、提供服务以及从事其他经营活动的单位和个人**，对外发生经营业务收取款项，收款方应当**向付款方开具发票**。

### 第 20 条 · 特殊情形
| 情形 | 开票规则 |
|---|---|
| 收购（向农民收购农副产品） | 付款方向收款方开具发票 |
| 建筑安装 | 由付款方（建设方）开具发票 |
| 运输（货物运输） | 运输方开具发票 |
| 保险 | 保险机构开具发票 |
| 演出 / 体育 / 文化 / 旅游 / 餐饮 / 住宿 | 由收款方开具 |

### 第 21 条 · 开具要求（**最关键条款**）
1. **项目齐全**：日期 / 数量 / 单价 / 金额 / 对方单位名称 / 商品名称（含规格型号）/ 服务名称等必须**逐项填写**
2. **填写规范**：字迹清楚、不得涂改、票面内容不得**品名与实际不符**
3. **盖章要求**：开票方必须**加盖发票专用章**（电子发票可使用电子发票专用章）
4. **特殊品种**：开具增值税专用发票 + 防伪税控系统开具（最高安全级别）

### 第 22 条 · 选择编码
- 纳税人应按规定开具发票，并按规定的时限、顺序、栏目、如实开具。

### 第 23 条 · 大写金额
- 发票金额**大写**与**小写**必须一致。

### 第 24 条 · 发票联次用途
- 任何单位和个人**不得转借、转让、代开发票**。
- 未经税务机关批准，**不得拆本使用发票**。
- 不得**自行扩大专业发票适用范围**。

### 第 26 条 · 保管期限
- **原始凭证保管期限**：一般 **10 年**
- **涉及重大金额或重要的会计凭证**：**30 年**
- **永久保管**：年度财务报告、会计档案保管清册、销毁清册
- 已开具的发票存根联和发票登记簿，应当**保存 5 年**

### 第 27 条 · 缴销
- 纳税人**注销税务登记** → 应当**向税务机关缴销发票**

## 5. 第六章 罚则（高频审核点）

### 第 33 条 · 应当开具未开具 / 未按规定开具
- 责令改正 + **1 万元以下**罚款
- 有违法所得的予以没收

### 第 34 条 · 以其他凭证代替发票
- 责令改正 + **1 万元以下**罚款

### 第 35 条 · 扩大使用范围 / 自行扩大专业发票适用范围
- 责令改正 + **1 万元以下**罚款

### 第 36 条 · 跨规定使用区域
- 责令改正 + **1 万元以下**罚款

### 第 37 条 · 损（撕）毁发票
- 责令改正 + **1 万元以下**罚款

### 第 34、35、36 条 · 大额情节严重情形
- 情节严重的，处**1 万元以上 3 万元以下**罚款

### 第 38 条 · 虚开发票（**关联刑法 205 条**）
- 没收违法所得 + 虚开金额 **1 倍以上 5 倍以下**罚款
- 情节严重 → **移送司法机关**
- 详见 `cases/虚开发票案例与司法解释.md`

### 第 39 条 · 非法制造发票防伪专用品 / 伪造发票监制章
- 没收作案工具 + 没收违法所得 + **1 万元以上 5 万元以下**罚款
- 情节严重的 → **5 万元以上 50 万元以下**罚款 + 移送司法机关

### 第 40 条 · 非法印制发票 / 伪造变造 / 非法制造发票防伪专用品 / 伪造发票监制章
- 详见 §39，并触犯刑法 → 移送

### 第 41 条 · 持有以假充真的发票
- 没收 + **1 万元以下**罚款

### 第 42 条 · 丢失发票
- **于发现丢失当日书面报告税务机关**
- 责令改正 + 可处 **1 万元以下**罚款
- 情节严重的 → **1 万元以上 3 万元以下**罚款

### 第 43 条 · 未按照规定存放和保管发票
- 责令改正 + 没收非法所得 + **1 万元以下**罚款

### 第 44 条 · 拒绝检查 / 隐瞒 / 谎报 / 拒不提供 / 伪造 / 变造 / 隐匿账簿凭证
- 责令改正 + **1 万元以下**罚款；情节严重 **1 万-5 万元**

### 第 45-49 条 · 行政处罚裁量与救济
- 一般程序 / 听证程序 / 复议 / 诉讼等程序性规定

## 6. 提炼：可机审的判定要素（17 项）

### 6.1 形式合规类（C 类，12 项）

| ID | 触发条件 | 来源 | 风险等级 |
|---|---|---|---|
| C01 | 项目不齐全（缺日期/品名/规格型号/单价/金额等任一项） | §21 | warning |
| C02 | 字迹涂改或票面内容不实 | §21 | warning |
| C03 | 小写金额与大写金额不符 | §23 | **violation** |
| C04 | 未加盖发票专用章 | §21 | **violation** |
| C05 | 品名与实际经营业务不符（如卖电脑开"办公用品"） | §21 | **violation**（行业俗称"变名开票"） |
| C06 | 使用已注销纳税人的发票 | §27 | **violation** |
| C07 | 跨规定使用区域（适用电子发票） | §36 | warning |
| C08 | 自行扩大专业发票适用范围 | §35 | warning |
| C09 | 拆本使用发票（未经税务机关批准） | §24 | **violation** |
| C10 | 转借、转让、代开发票 | §24 | **violation** |
| C11 | 未套印全国统一发票监制章 | §8 | **violation** |
| C12 | 票号与发票代码逻辑错误 | 总则 | warning |

### 6.2 时效类（T 类，3 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| T01 | 发票丢失后**当日**未报告 | §42 | warning |
| T02 | 注销税务登记时**未缴销**发票 | §27 | **violation** |
| T03 | 发票存根**未保存 5 年** | §26 | warning |

### 6.3 虚开类（X 类，2 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| X01 | 为他人虚开 / 为自己虚开 / 让他人为自己虚开 / 介绍他人虚开 | §38 + 刑法 205 | **critical**（刑责） |
| X02 | 票面金额与实际结算金额显著不符（如开 100 万实结 80 万） | §21 + §38 | **violation**（疑似虚开） |

## 7. 进项税额抵扣的额外规则（指引到增值税法文件）

- 用于**应税项目**的进项税：可抵扣
- 用于**免税项目**的进项税：不可抵扣
- 用于**集体福利 / 个人消费**的进项税：不可抵扣
- 用于**简易计税方法**的进项税：不可抵扣
- 非正常损失（管理不善造成被盗、丢失、霉烂）的进项税：不可抵扣
- 来源：增值税暂行条例第十条 / 增值税法实施细则（待 2026 年同步）
