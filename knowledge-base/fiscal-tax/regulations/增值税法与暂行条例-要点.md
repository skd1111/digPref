## 1. 暂行条例核心条款（**2026-01-01 前有效**）

### 第 1 条 · 征税范围
在中华人民共和国境内销售货物或者加工、修理修配劳务（**以下简称劳务**），销售服务、无形资产、不动产，**进口货物**的单位和个人，为增值税的纳税人。

### 第 2 条 · 税率结构（**截至 2026-01-01**）

| 纳税人 | 税率 |
|---|---|
| 一般纳税人销售 / 进口货物（销售 / 进口粮食、食用植物油、自来水、燃气等特定货物） | **9%** |
| 一般纳税人销售 / 进口图书、报纸、杂志等；自来水、暖气、冷气、热水、煤气、石油液化气、天然气、沼气、居民用煤炭制品；饲料、化肥、农药、农机、农膜；国务院规定的其他货物 | **9%** |
| 销售 / 进口交通运输服务、邮政服务、基础电信服务、建筑服务、不动产租赁服务、销售不动产、转让土地使用权 | **9%** |
| 一般纳税人销售 / 进口其他应税货物 / 劳务 | **13%** |
| 一般纳税人销售 / 进口现代服务（研发 / 技术 / 信息技术 / 鉴证 / 广告 / 鉴证 / 销售无形资产等） | **6%** |
| 一般纳税人销售 / 进口金融服务 / 生活服务 / 增值电信服务 / 销售土地使用权之外的其他无形资产 | **6%** |
| 出口货物（除另有规定外） | **0%** |
| 小规模纳税人 | **3%**（征收率，应税销售额×3%） |

### 第 4 条 · 起征点（**2019 起标准**）
- 按期纳税 → 月销售额 **5000-20000 元**
- 按次纳税 → 每次（日）销售额 **300-500 元**
- 各省可在上述范围内浮动

### 第 8 条 · 不得抵扣进项税额
1. 用于**简易计税方法**计税项目
2. 用于**免征增值税**项目
3. 用于**集体福利**或者**个人消费**
4. **非正常损失**（自然灾害除外）：因管理不善造成被盗、丢失、霉烂、变质的损失，以及因违反法律法规造成依法被没收、销毁、拆除的损失
5. 购进的**餐饮服务、居民日常服务和娱乐服务**
6. 购进的**贷款服务**（利息支出）、**转让金融商品**的支出
7. 国务院规定的其他情形

### 第 10 条 · 税率适用
- 兼营不同税率货物 / 劳务 → **未分别核算** → **从高适用**税率

### 第 11 条 · 小规模纳税人
- 年应征增值税销售额 ≤ **500 万元**（财政部、税务总局规定）
- 2018-05-01 起，工业和商业 50 万元 / 月销售额（年 500 万）作为分类标准
- 计税方法：**销售额 ÷ (1 + 征收率) × 征收率**

## 2. 《增值税法》（**2026-01-01 起施行**）新法核心变化

### 2.1 立法层面
- 从**国务院条例**上升为**全国人大常委会法律**——增值税的法律层级提升
- 但**总体税负保持稳定**，实施条例同步修订

### 2.2 视同应税交易（**新法独立章节**）
- 销售代销货物
- 设立资金账户 / 信用卡账户 / 储值卡（**新增视同销售**）
- 视同销售服务、无形资产
- 国务院规定的其他情形

### 2.3 简易计税的特殊规定
- **3% → 5%** 的过渡安排（部分服务维持 5% 征收率）
- **小规模纳税人标准**：从**年销售额 500 万**调整为**季度销售额 30 万**
- 起征点**法定化**为月销售额 **1 万元**

### 2.4 重大变化点
1. **明确"以票控税"+ "以数治税"双轨**（税收大数据 + 发票电子化）
2. **取消部分行业简易计税 5% 优惠**，统一回到 3%
3. 平台经济首次纳入**直接监管**——平台企业代开发票义务
4. 出口退税法律法规依据明确
5. 关联方申报、跨境服务等专门细化

## 3. 增值税征管的实际业务审核重点

### 3.1 一般纳税人审核核心

| 审核点 | 关注 |
|---|---|
| 税率适用是否正确 | 不同行业不同税率（13% / 9% / 6%） |
| 进项税额是否能抵扣 | 第 8 条 7 类情形 |
| 是否选择简易计税 | 备案制——选择了简易计税 36 个月不得变更 |
| 销售额是否真实 | 资金流 / 货物流 / 发票流 三流一致 |
| 关联交易是否独立交易定价 | 同企业所得税法第 42 条 |
| 出口退税单证是否齐全 | 出口货物报关单 + 出口发票 + 收汇凭证 |
| 享受优惠政策是否合规 | 残疾人就业即征即退 / 软件即征即退 / 资源综合利用等 |

### 3.2 小规模纳税人审核核心

| 审核点 | 关注 |
|---|---|
| 是否正确登记为小规模纳税人 | 标准：连续 12 个月销售额 ≤ 500 万 |
| 季度销售额是否超过起征点 | 9 万 / 季度（即月 3 万） |
| 发票开具是否合规 | 月 3 万元以下免征增值税 |
| 是否存在**不应享受减免税而享受**的情形 | 例如将货物销售挂服务 |

### 3.3 进项税额专项风险点（虚开重点）

| 类型 | 风险描述 |
|---|---|
| **农产品收购发票虚开** | 高发——通过虚开农产品收购发票虚增进项税抵扣 |
| **货物运输发票虚开** | 较高——海运 / 陆运费虚开 |
| **海关进口增值税专用缴款书** | 中等——伪造或重复使用抵扣凭证 |
| **异常增值税扣税凭证** | 真实发票但因供应商失联、走逃户等被风控 |
| **跨期取得发票** | 增值税专用发票取得后应在 360 日内认证（2019 后已取消认证，但有申报抵扣期限） |
| **增值税专用发票虚开** | 最严重——刑法第 205 条 |

## 4. 提炼：可机审的判定要素（24 项）

### 4.1 税率与销售额类（S 类，8 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| S01 | 税率适用错误（13% 货物错开 9% 或 6%） | 第 2 条 | **violation** |
| S02 | 兼营未分别核算（从高适用未启动） | 第 10 条 | warning |
| S03 | 销售额归集错误（货物销售错计入服务） | 第 1 条 | **violation** |
| S04 | 视同销售未申报（如将自产货物用于员工福利） | 第 4 条细则 | **violation** |
| S05 | 销售额超过小规模标准未及时认定一般纳税人 | 第 11 条 | warning |
| S06 | 季度销售额 < 起征点但未享受免征 | 第 4 条 | 中性（影响申报准确性）|
| S07 | 出口退税销售额未申报 / 申报错误 | 第 4 条细则 | **violation** |
| S08 | 差额计税销售额计算错误（如扣除额超规定） | 财税公告 | warning |

### 4.2 抵扣类（C 类，10 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| C01 | 用于集体福利 / 个人消费的进项抵扣 | 第 8 条 | **violation**（须做进项转出） |
| C02 | 购进餐饮服务 / 居民日常服务抵扣 | 第 8 条 | **violation** |
| C03 | 购进贷款服务 / 金融商品转让抵扣 | 第 8 条 | **violation** |
| C04 | 非正常损失的货物抵扣（如管理不善霉变） | 第 8 条 | **violation** |
| C05 | 取得虚开发票抵扣 | 第 8 条 + 刑法 | **critical** |
| C06 | 取得与本企业无关的发票抵扣 | 第 8 条 | **violation** |
| C07 | 简易计税项目取得专票抵扣 | 第 8 条 | **violation** |
| C08 | 免税项目取得专票抵扣 | 第 8 条 | **violation** |
| C09 | 跨期认证（一般不存在此问题） | 第 8 条 | warning |
| C10 | 海关进口增值税缴款书超期未申报 | 细则 | **violation** |

### 4.3 发票开具类（F 类，6 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| F01 | 应当开具未开具发票 | 发票办法第 33 条 | warning |
| F02 | 变名开票（如卖电脑开办公用品） | 发票办法第 21 条 | **violation** |
| F03 | 未按规定开具税率栏（如应 13% 开 9%） | 第 21 条 | warning |
| F04 | 红字发票申请不符合条件 | 细则 | warning |
| F05 | 红字发票未在规定时限内申请 | 细则 | warning |
| F06 | 即征即退申请不符规定 | 财税公告 | warning |

## 6. 与新法 2026-01-01 衔接（重要）

### 6.1 过渡期安排
- **2025-12-31 之前**：按现行《暂行条例》执行
- **2026-01-01 起**：按《增值税法》及其实施条例执行
- 现有纳税人不自动变更——**发证 / 备案 / 计税方法**登记，可能需要重新备案

**核心提示**：增值税审核 + 发票办法审核的**联动**是财税审核专家系统的核心——增值税申报数据异常（虚增进项、错配税率、虚开专票）与发票管理异常（变名、虚开、未盖专票章、票号跳号）通常**同时发生**。EAIDE 应建立**双向交叉验证**：发票数据 + 申报数据 + 资金数据 三位一体。
