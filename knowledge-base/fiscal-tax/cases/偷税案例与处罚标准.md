# 偷税案例与处罚标准（征管法第 63-66 条对应）

> **核心条款**：税收征管法第 63 条（偷税）+ 第 64 条（编造虚假计税依据）+ 第 66 条（骗税）+ 第 68 条（逾期未缴）。
>
> **刑法衔接**：刑法第 201 条（逃税罪）+ 第 204 条（骗取出口退税罪）+ 第 271 条（职务侵占罪）。
>
> **来源**：中国法院网、最高检发布案例、最高法公报。

---

## 1. 征管法第 63 条——偷税构成要件与处罚

### 1.1 偷税四种情形

| 编号 | 行为 | 法律含义 |
|---|---|---|
| 1 | **伪造 / 变造 / 隐匿 / 销毁账簿和记账凭证** | 提供假账证据链条 |
| 2 | **在账簿上多列支出或者少列收入** | 调整应纳税额下限 |
| 3 | **经税务机关通知申报而拒不申报** | 主观拒绝申报义务 |
| 4 | **进行虚假纳税申报** | "虚假"必须**重大且带有主观故意** |

### 1.2 行政处罚幅度（**50%-5 倍**）

| 偷税情形 | 处罚 |
|---|---|
| 普通偷税 | 追缴税款 + 加收滞纳金 + **50%-5 倍**罚款 |
| 构成逃税罪（刑法 201 第 1 款） | 移送公安机关 + 刑事追诉 |

### 1.3 刑事追诉标准（**刑法第 201 条**）

| 条件 | 标准 |
|---|---|
| 须同时满足 | ① 纳税人**采取欺骗、隐瞒手段**进行虚假纳税申报 ② **不缴或者少缴**应纳税款 |
| 数额 + 比例 | 数额**≥ 10 万元** + 占应纳税额 **30% 以上** |
| 量刑 | **3 年以下**有期徒刑或拘役 + **罚金** |
| 数额巨大 + 比例 | 数额**≥ 50 万元** + 占应纳税额 **30% 以上** |
| 量刑 | **3-7 年**有期徒刑 + **罚金** |

### 1.4 **首违不罚**与不予追诉（**关键抗辩**）

**刑法第 201 条第 4 款（修订新增）**：
> 经税务机关下达追缴通知后，补缴应纳税款、缴纳滞纳金、接受行政处罚的，**不予追究刑事责任**。
> 但是，**5 年内因逃税受过刑事处罚或者被税务机关给予 2 次以上行政处罚**的除外。

**实务解读**：
- 第一次逃税 + 主动补缴 + 滞纳金 + 罚款 → **免于刑事追诉**
- 第二次逃税 → **必然刑事追诉**

## 2. 征管法第 64 条——编造虚假计税依据（特殊情形）

### 2.1 情形
- **编造虚假计税依据** → 但未实际造成少缴税款（如拟申报时被发现）

### 2.2 处罚
- 责令限期改正 + **50000 元以下**罚款
- 情节严重 → **50000-100000 元**罚款

### 2.3 实务
- 常见于**未实际申报**即被发现的虚开专票
- 与"偷税"的区别：**主观目的**是否偷税

---

## 3. 征管法第 66 条——骗税构成要件与处罚

### 3.1 骗税两种情形

| 编号 | 行为 |
|---|---|
| 1 | **假报出口或者其他欺骗手段**，骗取国家出口退税款 |
| 2 | **虚开发票 / 伪造有关凭证**骗取退税 |

### 3.2 行政处罚
- 追缴税款 + **1-5 倍**罚款
- **3 年内**不得享受出口退税

### 3.3 刑事追诉（**刑法第 204 条**）

| 数额 | 量刑 |
|---|---|
| 数额较大（**≥ 5 万元**） | **5 年以下**有期徒刑或拘役 + 罚金 |
| 数额巨大（**≥ 50 万元**） | **5-10 年**有期徒刑 + 罚金 |
| 数额特别巨大（**≥ 500 万元**） | **10 年以上**有期徒刑或无期徒刑 + 罚金或没收 |

## 4. 征管法第 68 条——逾期未缴

### 4.1 计算（**特别注意**）

| 项目 | 标准 |
|---|---|
| 滞纳金比率 | **万分之五/日**（年化 18.25%） |
| 滞纳金起算 | 应缴期限届满次日起 |
| 滞纳金截止 | 实际缴纳之日 |
| 滞纳金扣除 | **企业所得税不得扣除** |

### 4.2 计算示例

某企业应缴增值税 **10 万元**，迟延 **30 天**才缴：
- 滞纳金 = 10 万 × 0.05% × 30 = **1500 元**
- 总计 **101,500 元**

某企业延迟 **365 天**：
- 滞纳金 = 10 万 × 0.05% × 365 = **18,250 元** ≈ **18.25%（年化）**

## 6. 处罚金额倍数与犯罪数额对照表（**实务必备**）

| 偷税额（万元） | 占应纳税额比例 | 行政处罚 | 刑事追诉 |
|---|---|---|---|
| **< 10** | **< 30%** | 50%-5 倍罚款 | 不追诉 |
| **≥ 10** | **≥ 30%** | 50%-5 倍罚款 | **3 年以下**有期 |
| **≥ 10** 但 **< 50** | **< 30%** | 50%-5 倍罚款 | 不追诉（仅行政处罚） |
| **≥ 50** | **≥ 30%** | 50%-5 倍罚款 | **3-7 年**有期 |
| **≥ 50** | **< 30%** | 50%-5 倍罚款 | 不追诉 |
| 任意 | 任意 + **5 年内 2 次行政处罚或刑事前科** | 行政 | **必须刑事** |

## 7. 偷税手段分类识别要点

### 7.1 三大传统偷税手段

| 手段 | 典型识别 |
|---|---|
| **隐匿收入** | (a) 大额现金不入账；(b) 私卡收款；(c) 委托第三方走账；(d) 关联客户不入账 |
| **虚列支出** | (a) 虚开成本发票；(b) 虚增工资；(c) 虚增折旧摊销；(d) 资本化支出费用化 |
| **虚假申报** | (a) 申报收入显著低于实际；(b) 申报扣除显著超过限额；(c) 适用税率错误 |

### 7.2 偷税 vs. 避税 vs. 漏税

| 类型 | 实质 | 法律地位 |
|---|---|---|
| **偷税** | 主观故意 + 隐瞒 / 虚假 | **违法** + 可能**犯罪** |
| **抗税** | 暴力 / 威胁 | **违法** + 可能**犯罪** |
| **骗税** | 骗取国家税款 | **违法** + 可能**犯罪** |
| **避税** | 利用税法不完善减少纳税义务 | **不违法**（非违法但道德争议） |
| **漏税** | 由于疏忽 / 不懂税法导致 | 一般不违法 + 补缴 + 滞纳金 |
| **逃税** | 偷税的刑法概念 | 犯罪 |

### 7.3 实务识别要点（**AI 审核重点**）

| 识别要素 | 含义 |
|---|---|
| **资金流 vs 申报流** | 银行流水 - 申报收入 > 5% 异常 |
| **货物流 vs 发票流** | 出入库单 - 已开发票 偏差 > 10% |
| **票流 vs 物流** | 上下游对开票 / 货物流反向 |
| **员工 vs 申报工资** | 员工个税申报显著低于同行业 |
| **行业税负 vs 个别税负** | 个别企业税负显著低于行业 |

## 8. 提炼：可机审的判定要素（25 项）

### 8.1 偷税构成要件类（T 类，6 项）

| ID | 触发 | 处罚 |
|---|---|---|
| T01 | 私卡收款 ≥ 1 万元（且未申报） | 50%-5 倍 |
| T02 | 现金销售不入账 | 50%-5 倍 |
| T03 | 隐瞒销售退回 / 折让 | 50%-5 倍 |
| T04 | 关联客户不开发票 | 50%-5 倍 |
| T05 | 虚列工资薪金 | 50%-5 倍 |
| T06 | 多列成本 / 资产 / 折旧 | 50%-5 倍 |

### 8.2 刑事追诉类（C 类，4 项）

| ID | 触发 | 后果 |
|---|---|---|
| C01 | 偷税 ≥ 10 万元 + ≥ 30% 应纳税额 | 3 年以下 + 罚金 |
| C02 | 偷税 ≥ 50 万元 + ≥ 30% 应纳税额 | 3-7 年 + 罚金 |
| C03 | 5 年内 2 次行政罚款 | 必然刑事追诉 |
| C04 | 5 年内 1 次刑事 + 再次偷税 | 必然刑事 + 加重 |

### 8.3 行政处罚类（A 类，8 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| A01 | 应缴未缴 + 滞纳金超过 30 天 | 第 68 条 | warning |
| A02 | 滞纳金超过 1 年未清缴 | 第 68 条 | **violation** |
| A03 | 转让定价独立交易偏离 | 第 42 条 | **violation** |
| A04 | 关联交易资料未提交 | 第 44 条 | **violation** |
| A05 | 申报延期未事前申请 | 第 27 条 | warning |
| A06 | 缴税延期未事前申请 | 第 31 条 | warning |
| A07 | 注销清算未清税 | 第 33 条 | **violation** |
| A08 | 拒绝 / 阻碍税务检查 | 第 70 条 | **violation** |

### 8.4 编造虚假计税依据类（F 类，3 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|
| F01 | 申报数据虚假（如虚假申报） | 第 64 条 | **violation** |
| F02 | 前后申报重大矛盾 | 第 64 条 | warning |
| F03 | 账簿凭证伪造 | 第 63 条 + 64 | **violation** |

### 8.5 骗税类（E 类，4 项）

| ID | 触发 | 来源 | 风险 |
|---|---|---|---|

| E02 | 虚开专票骗取退税 | 第 66 条 + 刑法 204 | **critical** |
| E03 | 出口退税单证不齐 | 第 66 条 | **violation** |
