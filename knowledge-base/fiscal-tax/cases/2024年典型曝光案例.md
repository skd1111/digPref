## 二、网络主播偷逃税典型案例

### 案例 1 · 主播"曲曲大女人"（乐传曲）

| 项目 | 内容 |
|---|---|
| **当事人** | 乐传曲（网名"曲曲大女人"），情感类博主 |
| **注册地** | 上海 |
| **活动平台** | 抖音 / 小红书 / 微博 |
| **违规期间** | 2020-2022 年 |
| **违规手段** | （1）通过个人账户收款隐匿销售收入；（2）将个人劳务报酬所得转换为个体工商户经营所得 |
| **处理机关** | 国家税务总局上海市税务局第四稽查局 |
| **追缴 + 罚款** | **758 万元**（含税款 + 滞纳金 + 罚款） |
| **状态** | 已缴清全部款项 |
| **典型意义** | 体现"金税四期"大数据比对能力——平台收入、银行流水、税务申报三重对比发现隐匿收入 |

### 案例 2 · 主播"烧伤超人阿宝"（宁方刚）

| 项目 | 内容 |
|---|---|
| **当事人** | 宁方刚（网名"烧伤超人阿宝"），原积水潭医院医生 |
| **违规问题** | 自媒体平台赞赏 / 咨询收入未申报纳税 |
| **追缴金额** | 846,367.61 元 |
| **性质** | 补缴 + 滞纳金 |
| **举报人** | 艾芬（继续举报带货方面涉税问题） |

### 案例 3 · 河南洛阳马海涛、梁娜夫妻

| 项目 | 内容 |
|---|---|
| **当事人** | 马海涛、梁娜夫妻（网络主播） |
| **违规期间** | 2020-2022 年 |
| **违规手段** | 隐匿直播带货佣金收入 |
| **少缴税费** | 207 万元 |
| **追缴 + 罚款** | 317 万元（合计） |

### 行业整治新趋势

| 措施 | 实施时间 |
|---|---|
| **大数据监管**（税收大数据比对） | 2024 全年 |
| **平台数据透明化**（按月报送主播身份信息与收入） | 2024 起新规 |
| **自查从轻政策**（主动补税罚款减半） | 多地试点 |
| **MCN 调整分成模式** | 自发整改 |
| **税收信用黑名单** | 试点 + 推开（限制商业活动） |

### 案例 5 · 新疆图木舒克东城迎宾加油加气站

| 项目 | 内容 |
|---|---|
| **当事人** | 图木舒克东城迎宾加油加气站 |
| **追缴金额** | 793 万元 |

### 案例 6 · 云南文山丘北县树皮岔路加油站

| 项目 | 内容 |
|---|---|
| **当事人** | 丘北县树皮岔路加油站 |
| **问题** | 通过内部价差 + 现金销售隐匿 |

### 行业规律
- 加油站偷税多发于**个体加油站 / 民营连锁**
- 手段：**现金销售不入账** + **加油员个人账户收款**
- 税务大数据 + **ETC / 加油机计量数据** 可精准识别销售偏差
