# 虚开发票案例与司法解释

> **核心法规**：《中华人民共和国刑法》第 205 条；《最高人民法院关于虚开增值税专用发票定罪量刑标准有关问题的通知》（法〔2018〕226 号）。
>
> **最新政策**：最高人民法院 2025-11 发布的 8 起涉税犯罪典型案例，其中明确**"虚开专票与逃税罪竞合时择一从重"**原则。
>
> **来源**：[中国法院网](https://www.chinacourt.org.cn/) · [最高人民法院](https://www.court.gov.cn/)

---

## 1. 刑法第 205 条全文（**核心条款**）

> **虚开增值税专用发票或者虚开用于骗取出口退税、抵扣税款的其他发票**
> （以下简称虚开增值税专用发票）

### 1.1 四种虚开情形

| 编号 | 行为 | 英文 |
|---|---|---|
| 1 | **为他人虚开** | 开票方无实际经营业务而开具发票给他人 |
| 2 | **为自己虚开** | 票面金额用于自身进项抵扣 |
| 3 | **让他人为自己虚开** | 收票方要求第三方开具与实际经营业务不符的发票 |
| 4 | **介绍他人虚开** | 介绍 / 撮合虚开行为 |

### 1.2 量刑标准（**3 档**）

| 刑档 | 触发条件 | 主刑 | 罚金 |
|---|---|---|---|
| **基础档** | 虚开税款数额 **较大** 或有其他**严重情节** | **3 年以下**有期徒刑或拘役 + 罚金 | **2 万 - 20 万元** |
| **加重档** | 虚开税款数额**巨大** 或有其他**特别严重情节** | **3-10 年**有期徒刑 + 罚金 | **5 万 - 50 万元** |
| **最重档** | 虚开税款数额**特别巨大** 或有其他**特别严重情节** | **10 年以上有期徒刑或无期徒刑** + 罚金或没收财产 | **5 万 - 50 万元**或没收 |

### 1.3 数额标准（**法〔2018〕226 号**）

| 档次 | 数额区间 | 标准依据 |
|---|---|---|
| **较大** | 虚开税款 **≥ 5 万元** | 旧司法解释：1-5 万 → 较大 |
| **巨大** | 虚开税款 **≥ 50 万元** | 旧司法解释：5-50 万 → 巨大 |
| **特别巨大** | 虚开税款 **≥ 500 万元** | 2018 新标准 |

> ⚠ 金额标准存在地区差异（如北京 / 上海 / 经济发达地区可能细化），实际量刑以**省级法院**具体标准为准。

## 2. 立案追诉标准（**"两高"《关于办理涉税刑事案件的若干问题的解释》**）

### 2.1 立案追诉标准
- 虚开税款 **≥ 5 万元** + 致使国家税款损失 **≥ 3 万元** → **应予立案**

### 2.2 数额较大标准
- 虚开税款 **≥ 10 万元**（部分文献指 **≥ 5 万元**，以**两高解释**为准）

### 2.3 不予追诉情形（**重要**）
- 虚开专票用于**本企业正常经营活动** + **如实申报** + **未骗取**抵扣 → **一般情况下不予追诉**
- 真实挂靠经营 + 不具有骗税目的 + 无偷骗税故意 → **不予定罪**（**最高法 2025.11 典型案例**）

## 3. 最高法 2025-11 典型案例（**重要判例**）

### 案例 A · **虚开专票应"两罪择重"**

| 项目 | 内容 |
|---|---|
| **当事人** | 某公司法定代表人（化名） |
| **犯罪事实** | 让他人为自己虚开增值税专用发票用于抵扣进项税 |
| **关键点** | 虚开目的为 **逃税**，而非骗取国家税款 |
| **判决** | （一审）虚开增值税专用发票罪；（二审）改判为**逃税罪** |

**重要原则**：
> **当虚开增值税专用发票的目的是逃税时，应当结合主客观一致原则**，以逃税罪定罪量刑，**避免重罚**。

### 案例 B · **真实交易下的善意取得**

| 项目 | 内容 |
|---|---|
| **当事人** | A 企业（善意取得方） |
| **犯罪事实** | 取得虚开发票用于进项抵扣 |
| **关键点** | A 企业有**真实交易** + **未与开票方共谋** |
| **判决** | 不构成虚开增值税专用发票罪 |

> ⚠ 即使不构成刑事犯罪，**行政**上仍需**进项转出**（虚增进项）+ **缴纳税款 + 滞纳金**。

### 案例 C · **挂靠经营有真实业务**

| 项目 | 内容 |
|---|---|
| **当事人** | 夏某（挂靠人） |
| **犯罪事实** | 挂靠在某建筑公司，对外以被挂靠方名义开具发票 |
| **关键点** | **有真实货物购销** + **资金流、发票流、货物流三流一致** |
| **判决** | 不构成虚开增值税专用发票罪（但构成**偷税**） |

> ⚠ 法律上"挂靠"形成的关系复杂，**三流一致**是判断真实交易的关键。

### 案例 D · 主动补缴降一档刑

| 项目 | 内容 |
|---|---|
| **当事人** | 李某 |
| **基础事实** | 虚开专票数额巨大（≥50 万）→ 应判 **3-10 年** |
| **从宽情节** | 自愿如实供述 + 主动补缴税款 + 配合调查 |
| **判决** | 实刑 **3 年**，缓刑 **4 年** + 罚金 **50 万元** |

### 案例 E-G · 数额特别巨大案件

| 案件 | 虚开金额 | 判决 |
|---|---|---|
| E（医药公司） | **2.7 亿元** | 主犯 **15 年** + 罚金 **50 万** |
| F（外贸企业） | **1.5 亿元** | 主犯 **12 年** + 罚金 **40 万** |
| G（科技公司） | **8000 万元** | 主犯 **10 年** + 罚金 **30 万** |

## 5. 虚开问题的核心识别要素（**AI 审核专用**）

### 5.1 形式识别

| 识别点 | 含义 |
|---|---|
| **品名不符** | 发票品名与实际业务不一致 |
| **金额异常** | 单笔金额明显高于 / 低于同类业务 |
| **买卖方关系异常** | 关联方 / 同一控制人 / 高频互开 |
| **上下游关联** | 上游被税务机关认定的失信 / 走逃户 |
| **发票来源地** | 来自高风险地区 / 园区 / 集中注销地区 |

### 5.2 业务实质识别（**核心**）

| 三流 | 含义 | 实质审查 |
|---|---|---|
| **货物流** | 货物的真实交付 | 物流单 / 出入库单 / 运输单 / 货代单 |
| **资金流** | 货款的真实支付 | 银行流水 / 网银支付 / 票据背书 |
| **发票流** | 发票的开具流转 | 销方 → 购方 的传递链路 |

> **三流一致**是判断真实交易的核心。无三流一致 → **触发虚开风险预警**。

### 5.3 数据指标识别

| 指标 | 阈值 | 识别含义 |
|---|---|---|
| **销项 / 进项比** | 1 个标准差以外 | 短期内突增 |
| **单张开票金额分位数** | > 99% 分位 | 大额发票 |
| **新成立的供应商** | 3 个月内新成立 | 虚开园区公司 |
| **进项转出比例** | > 10% | 异常转出 |
| **税负率波动** | > ±2% | 短期税负异常 |

## 7. 司法解释与国际比较（**背景**）

### 7.1 司法解释变更
- **2014 年 · 27 号文**：较为宽松 → 部分案件不予定罪
- **2018 年 · 226 号文**：较为严格 → 数额标准上调
- **2024-2025 年 · 最高法典型案例**（8 起）：明确**主客观一致原则** → 虚开用于逃税的择逃税罪定罪

### 7.2 罪数比较（**重要实务**）

| 罪数形态 | 法律适用 |
|---|---|
| 虚开专票 + 逃税 | **2025 起**择一从重处罚，**主要看主观目的** |
| 虚开专票 + 骗税 | 虚开 + 骗税（数罪并罚） |
| 虚开发票罪 + 偷税 | 偷税（征管法）+ 虚开（刑法） |

### 7.3 与英国 / 美国比较
- **美国 IRS** · 虚开与虚假申报税务犯罪重在**主观故意**与**金额**
- **英国 HMRC** · 主张"无合理理由" + 商业实质审查
- **中国** · 2025 司法解释思路与国际接轨，强调**主客观一致**
