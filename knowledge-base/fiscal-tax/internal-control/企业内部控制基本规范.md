> **主规范版本**：2008-05-22 财政部、证监会、审计署、银监会、保监会联合发布；自 **2009-07-01** 起在上市公司范围内施行。

## 2. 第一章 总则（**核心目标**）

### 第 1 条 · 立法目的
- 加强和规范企业内部控制
- 提高企业经营管理水平和**风险防范能力**
- 促进企业可持续发展
- 维护社会主义市场经济秩序

### 第 2 条 · 内部控制定义（**核心**）
> 内部控制是由企业董事会、监事会、经理层和全体员工实施的、旨在实现控制目标的过程。

### 第 3 条 · 内部控制目标（**5 项**）
1. 经营管理**合法合规**
2. 资产**安全**
3. 财务报告及相关信息**真实完整**
4. 提高经营**效率和效果**
5. 促进企业实现**发展战略**

### 第 4 条 · 内部控制 5 要素
1. **内部环境**（公司治理、机构设置、权责分配、内部审计、人力资源政策、企业文化、社会责任）
2. **风险评估**（目标设定、风险识别、风险分析、风险应对）
3. **控制活动**（授权审批、不相容职责分离、会计系统控制、财产保护、预算、运营分析、绩效考评、重大风险预警机制）
4. **信息与沟通**（内部信息传递、财务报告、信息系统、反舞弊）
5. **内部监督**（内部审计、专项检查、缺陷认定、整改）

### 第 5 条 · 内部控制 4 原则
- 全面性（含内部环境 + 决策、执行、监督全过程）
- 重要性（重点关注重要业务事项和高风险领域）
- 制衡性（治理结构 / 机构设置 / 权责分配 / 业务流程）
- 适应性（与经营规模、业务范围、竞争状况、风险水平相适应，并随情况变化调整）

## 3. 第二章 内部环境（**12 项要求**）

| 关注点 | 审核关键 |
|---|---|
| 公司治理 | 董事会、监事会、独立董事制度 |
| 机构设置 | 不相容职务分离 |
| 权责分配 | 授权审批明确 |
| 人力资源 | 招聘、培训、绩效、退出 |
| 企业文化 | 诚信合规、职业道德 |
| 社会责任 | 安全生产、产品质量、环境保护、促进就业、员工权益 |
| 内部审计 | 独立性、审计委员会 |

### 关键审核点（**重点**）：
- **董事长不兼任总经理**（法人治理结构）
- **董事会有审计委员会**
- **总会计师制度**（央企 / 大型上市公司）
- **不相容职务分离**（出纳与稽核 / 审批与执行 / 保管与记账分离）

## 4. 第三章 风险评估

### 第 20-26 条
- 设立**目标**：战略目标、经营目标、报告目标、合规目标、资产安全目标
- 风险识别：**日常经营**风险 + **战略**风险
- 风险分析：**定性** + **定量**（影响、可能性）
- 风险应对：**风险规避 / 风险降低 / 风险分担 / 风险承受**

## 5. 第四章 控制活动（**核心 9 项**）

### 第 27-28 条 · 授权审批控制
- **一般授权**（日常业务常规授权）
- **特别授权**（重大业务 / 非常规事项 专门授权）
- **金额** + **限额** + **流程** + **责任人**四要素

### 第 28 条 · 不相容职务分离（**关键**）
| 不相容岗位 | 含义 |
|---|---|
| 业务申请 vs 业务审批 | 不能一人 |
| 业务审批 vs 执行 | 不能一人 |
| 业务执行 vs 记录 | 不能一人 |
| 业务记录 vs 稽核 | 不能一人 |
| 财产保管 vs 会计记录 | 不能一人 |
| 财产保管 vs 财产清查 | 不能一人 |
| 货币资金保管 vs 货币资金记录 | 不能一人 |
| 货币资金保管 vs 货币资金审批 | 不能一人 |

### 第 30 条 · 会计系统控制
- 会计凭证 / 账簿 / 报表 / 财务电子信息系统
- **会计凭证**记录**经济业务的真实性、完整性、合规性**
- 重要业务（不限于）应当**实时反映**

### 第 31 条 · 财产保护控制
- 固定资产 / 存货 / 货币资金 / 无形资产 / 投资性房地产
- 实行**台账 + 卡片 + 实盘**制度
- 至少**年度一次全面盘点**

### 第 33 条 · 预算控制（**全面预算**）
- 编制 → 审批 → 执行 → 调整 → 决算 → 考核

### 第 34 条 · 运营分析
- 月度 / 季度 / 年度运营分析

### 第 35 条 · 绩效考评
- 个人 + 团队 + 部门 + 子公司

### 第 36 条 · 重大风险预警机制
- 重大风险事项**预警指标 + 报警机制 + 处置预案**

---

## 6. 第五章 信息与沟通

### 第 38 条 · 内部信息传递
- 内部报告体系
- **反舞弊**机制（**举报渠道 + 调查程序 + 保护措施**）

### 第 39-41 条 · 财务报告
- 财务报告**真实完整**
- 与税务 / 统计 / 监管等部门的信息沟通

---

## 7. 第六章 内部监督

### 第 43 条 · 内部审计
- 内部审计**独立于其他业务部门**
- 业务范围：**审计财务收支** + **内部控制** + **风险管理**

### 第 45-46 条 · 缺陷认定（**核心分级**）
| 缺陷等级 | 标准 | 影响 |
|---|---|---|
| **重大缺陷** | 可能导致严重偏离控制目标 | 一个或多个控制要素的缺失 |
| **重要缺陷** | 严重程度低于重大缺陷，但仍可能导致偏离 | 仍需关注 |
| **一般缺陷** | 除重大、重要以外的其他缺陷 | 改进 |

### 第 47 条 · 整改
- 对发现的缺陷**及时整改**

### 8.2 关键应用指引与审核要点

#### 指引 6 · 资金活动
- **资金支付**：申请 → 审批 → 复核 → 支付 → 复核
- **银行账户**：单一账户管理 → **银行印鉴 + 网银盾分级管理**（会计 + 出纳 + 复核人）
- **资金集中 / 归集**：集团型企业的大额资金调度
- **筹资活动**：股东借款 / 银行贷款 / 债券 / 股权融资 → **重大事项经董事会审议**

#### 指引 7 · 采购业务
- **采购申请 → 审批 → 询价 → 验收 → 入账**
- **不相容职务**：申请 / 审批 / 询价 / 验收 / 付款 必须分离
- **重要物资 / 大额采购** 应 **公开招标 / 集中采购**

#### 指引 8 · 资产管理
- **存货 / 固定资产**出入库管理
- **年度盘点** + **月度抽查**
- **闲置资产处置**：评估 → 审批 → 处置 → 入账

#### 指引 9 · 销售业务
- 销售合同 → 订单 → 收发货 → 收款 → 入账
- **应收账款管理**：信用评估 / 账龄分析 / 催收
- **坏账准备** 按账龄计提

#### 指引 10 · 工程项目
- **项目立项** → **概算** → **招投标** → **施工** → **结算** → **决算** → **资产入账**
- **项目变更** 必须经原审批单位批准
- **重大工程** → **集团董事会审议**

#### 指引 11 · 担保业务（**高风险**）
- **严禁**对实际控制人 / 关联方 / 子公司违规担保
- **总额** 不得超过公司章程规定
- **单笔超过限额** 必须经股东会审议

#### 指引 12 · 业务外包
- **外包合同** 必须明确 SLO / KPI / 数据安全
- **数据安全** + **保密责任**

#### 指引 13 · 财务报告
- **编制 → 复核 → 审批 → 报送**
- **会计政策** 应一惯性（与基本准则对接）
- **会计差错** 识别 + 更正 + 披露

#### 指引 14 · 全面预算
- **预算编制**（上下结合）
- **预算执行** + **预算控制**（刚性 + 柔性）
- **预算调整** 必须按原审批权限
- **决算与考核**

#### 指引 15 · 合同管理
- **合同调查 → 谈判 → 起草 → 审核 → 签订 → 执行 → 归档 → 后评估**

#### 指引 17 · 信息系统（**与 EAIDE 直接相关**）
- **信息系统**应当覆盖**全部关键业务**
- **数据备份** → 每日备份 + 异地存储
- **网络安全** → 边界防护 / 入侵检测 / 数据加密
- **应用系统** → 用户授权 + 操作日志 + 数据完整性

> ⚠ **指引 17 是 EAIDE 自身承担的内控合规目标**——本规范既约束 EAIDE，也用来评估 EAIDE 服务的财务系统。
