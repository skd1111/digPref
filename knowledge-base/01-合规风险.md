## 〇、风险定义与判定标准

### 1. 什么是合规风险

合规风险指企业（含金融机构、上市公司、央国企及其他市场主体）在经营管理和员工履职过程中，因**违反法律法规、监管规定、行业准则、国际条约及公司章程**，可能遭受**行政处罚、民事赔偿、刑事追究、商誉受损**的风险。

> 法律依据：
> - 国务院国资委《中央企业合规管理办法》第3条：合规，是指中央企业经营管理行为和员工履职行为**符合法律法规、监管规定、行业准则、国际条约及公司章程、相关国际规则等要求**。
>   - 来源：中国政府网，<https://www.gov.cn/zhengce/zhengceku/2022-09/19/content_5710633.htm>
>   - 本地下载：`D:\work\other\sources\01-合规\中国政府网_中央企业合规管理办法_2022.html`

### 2. 通用判定标准

合规审查员或文档扫描系统应同时检查以下五个维度，**任意一项命中即触发预警**：

| 维度 | 判定标准 |
|------|----------|
| 条款层级 | 触发条款是否属于法律/行政法规**强制性规定**（而非任意性、倡导性） |
| 利益失衡 | 条款是否**单方面免除/减轻提供方责任、加重相对方责任、排除相对方主要权利** |
| 显失公平 | 是否违反**公平原则、诚实信用原则、公序良俗** |
| 程序瑕疵 | 是否经过**显著提示（粗体/弹窗/单独告知）**、是否**履行说明义务** |
| 既往处罚 | 是否有**同类条款被市场监管、证监会、人民法院判罚**的案例 |

```
  按主题分类（合同/招投标/广告/劳动/制度/涉外）
       ↓
   命中条款人工二次确认 → 风险评级
       ↓
 输出"风险点报告"（含原文摘录、依据条款、建议改写）
```

### 11.2 关键命中阈值建议

| 命中类型 | 建议动作 |
|----------|----------|
| 命中"高"等级条款 ≥1 | 立即停止签署，提交法务/合规部门审查 |
| 命中"高"等级条款 ≥3 或 "中"等级条款 ≥5 | 升级至首席合规官审查 |
| 仅命中"低"等级条款 | 业务部门自查整改即可 |
| 同一文档两次审查均命中同类条款 | 提交合规复盘，建议修改模板 |

### 11.3 文档模板合规自检清单（起草阶段使用）

起草人起草文件时，应同时自检以下问题：

- [ ] 是否使用了对相对人不利的单方最终解释权表述？
- [ ] 是否包含绝对化、不可证实或贬损竞品的宣传表述？
- [ ] 是否单方面免除/减轻自身责任、加重对方责任？
- [ ] 是否设置违反《劳动合同法》关于违约金、试用期、竞业限制、社保的条款？
- [ ] 是否包含反商业贿赂、关联交易、内幕信息等内部合规必备条款（如适用）？
- [ ] 是否涉及涉外交易时遵循《出口管制法》《反外国制裁法》《数据出境安全评估办法》要求？
- [ ] 是否承诺遵守对中国具有域外效力的外国制裁法律（高危）？
- [ ] 涉及招投标时，是否含有量身定制资格条件、限制排斥潜在投标人的条款？
- [ ] 涉及上市公司公告时，是否存在选择性披露、内幕信息泄露风险？
