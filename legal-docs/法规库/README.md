# 法规库（审核模式知识库语料）

面向「审核专家 · 文档审核 / 系统合规审核」的公开法律法规全文语料，按业务域分目录存放，
可整目录或分域上传到应用内知识库（RAG），审核后每条风险会自动带「知识库依据」并回链原文。

- 总计 **209 篇**（法律/行政法规/司法解释 199 篇 + 部门规章 10 篇），全部为**现行有效**文本（效力状态 = 有效 / 已修改），已废止与尚未生效的一律未收录。
- 每篇文件头部 front matter 保留了：标题、制定机关、公布日期、施行日期、效力状态、效力层级、**权威原文链接**。
- 逐篇清单（含域、层级、机关、日期、效力、来源）见 [INDEX.md](INDEX.md)。

## 数据来源与授权说明

1. **法律 / 行政法规 / 司法解释 / 宪法 / 监察法规（199 篇）**
   镜像自开源文库 [`qundao/law-book`](https://github.com/qundao/law-book)（其原始来源为
   [国家法律法规数据库 flk.npc.gov.cn](https://flk.npc.gov.cn/)，文库由 markitdown 将官方 docx 转 md）。
   每篇 front matter 的 `urls` 即该法规在国家法律法规数据库的原始详情页，可逐条复核。
   抓取脚本与全量索引：`.law-download/`（`build_manifest.py` → `run_select.py` → `download.py`）。
2. **部门规章（10 篇）**
   直接抓取 [中国政府网政策文件库](https://www.gov.cn/zhengce/zhengceku/) 与 [国务院公报](https://www.gov.cn/gongbao/) 原文页，
   脚本 `.law-download/download_dept.py`，链接清单 `.law-download/dept_links.json`。

法律文本本身属于依法公开的公共信息；本目录仅用于内部合规审核参考，不作为法律依据。

## 怎么用于审核模式

1. 打开「审核专家 → 知识库 / 参考资料」页签；
2. 点「＋ 上传参考资料」，按目录批量选中 `.md` 文件（Vite/Tauri 对话框支持多选，建议一次传一个目录）；
3. 导入确认弹窗里每个文件的分类默认「自动识别」（由模型按内容判定，识别不准时逐条改成上表对应的分类）；
   工具栏左侧的分类下拉是**筛选器**（默认「全部」），只影响列表显示，不参与上传分类；
4. 等待状态从 `indexing` 变为完成（分块 + 向量化，进度自动轮询）；
5. 之后审核合同/制度/公告时，分析提示词会注入召回条文，风险卡片显示「知识库依据」，
   点击依据可直接预览原始 md 文件。

只想覆盖单一域时（例如只做财税合同审核），只上传 `01_财税` 即可，检索噪声更小。

## 已知范围限制

- 《个人信息出境标准合同办法》正文已入库，但其**附件「个人信息出境标准合同」模版**在 gov.cn 公报页即标注「略」，
  需从网信办官网（www.cac.gov.cn）单独下载合同范本全文。
- 未收录**地方性法规、地方规章、行业自律规则**（数量巨大，且企业内网审核一般以中央层面法规为准）。
- 未收录**尚未生效**的文本（如《审计法实施条例（2026）》《注册会计师法（2026）》），生效后可用 `.law-download` 脚本重新拉取。
- 法规会修订：如需更新，重跑 `.law-download/build_manifest.py`（重建索引，约 1.5 分钟）→ `run_select.py`（重选）→ `download.py`（增量下载，已存在文件跳过）。
